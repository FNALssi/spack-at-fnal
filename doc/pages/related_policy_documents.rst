Policy Documents Related to Spack
=================================

The documents below describe policies related to the use of Spack in SCD.
The current versions are maintained as ReST sources and published as HTML.

* :doc:`A Plan for Standard Builds of LArSoft <plan_for_standard_builds>`
  This document describes the plan for creating and publishing standard builds of LArSoft using Spack.
  Other experiments using part of the same software stack may also find this document useful.
  A similar plan will be developed for other software stacks supported by SCD.

* :doc:`A Plan for Maintaining Spack Recipes <recipe_maintenance>`
  This document describes the SCD plan for the maintenance of Spack recipes.
