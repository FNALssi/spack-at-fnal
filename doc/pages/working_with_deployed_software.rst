Working with Deployed Software
==============================

Most software for Fermilab experiments is deployed through Spack environments.
Much of your use of these spack environments will require you to have your own writable Spack instance.
This spack instance will be constructed with some other Spack instance (for example, your experiment's Spack instance) as an *upstream*.
The spack instance you create is usually called a *subspack*.
